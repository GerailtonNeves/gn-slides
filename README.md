# GN SLIDES PRO 4K - Sistema Profissional de Slideshows & Vídeos MP4

Sistema web completo para criação de vídeos e slideshows em 4K Ultra HD com abertura especial, encerramento, música de fundo, legendas por foto e transições variadas.

---

## 🚀 Como Subir para o GitHub

1. Acesse o site do [GitHub](https://github.com) e crie um novo repositório chamado `gn-slides-pro-4k`.
2. Abra o terminal (Prompt de Comando ou PowerShell) nesta pasta `GN_SLIDES_PRO_GITHUB` e rode os comandos:

```bash
git init
git add .
git commit -m "Initial commit - GN SLIDES PRO 4K"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/gn-slides-pro-4k.git
git push -u origin main
```

---

## ☁️ Como Hospedar na Vercel (Em 1-Clique)

1. Acesse [vercel.com](https://vercel.com) e faça login com sua conta do GitHub.
2. Clique em **"Add New..."** -> **"Project"**.
3. Selecione o repositório **`gn-slides-pro-4k`**.
4. Clique em **"Deploy"**.
5. Pronto! O seu sistema estará online em segundos em um link como `https://gn-slides-pro-4k.vercel.app`.

## 🔑 Recursos do Sistema Comercial

- **Licenciamento & Ativação PRO**: Validação de chaves e remoção da marca d'água.
- **Gerador de Licenças Admin**: Ferramenta no próprio painel para gerar chaves ilimitadas para clientes.
- **Modelos Prontos por Tema**: Igreja, Casamento, Aniversário, Saudades e Comercial.
- **Design Responsivo**: Adaptado para Celulares, Tablets e Computadores.
